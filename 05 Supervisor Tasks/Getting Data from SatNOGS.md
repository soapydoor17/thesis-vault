# Requesting New Observations

Go to specific satellite's/ground station's page and look at list of predicted passes
Can schedule any with a "Schedule" button
Once pass completes, client uploads the waterfall/audio automatically, and it can be fetched via API.

https://wiki.satnogs.org/Operation
NOTE: Cannot schedule new observations without having own registered ground station on the network
